**Самый быстрый способ, через сайт GitHub:**
1. Зайдите на github.com → **New repository**. Назовите его, например, `snake`, сделайте публичным и создайте.
2. Нажмите **uploading an existing file**, перетащите `index.html` и нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем **Save**.
4. Через 1–2 минуты игра будет доступна по адресу `https://ВАШ_ЛОГИН.github.io/snake/`.

**Через командную строку**, если у вас установлен git:
```
mkdir snake && cd snake
# положите сюда index.html
git init && git add . && git commit -m "Snake game"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/snake.git
git push -u origin main
```
Затем включите Pages в настройках, как в шаге 3.

Файл полностью самодостаточный, ничего дополнительно подключать не нужно. Если что-то не получится, напишите, на каком шаге застряли.

**Режимы.** Перед началом игры (и после проигрыша) выбирается фигура. Её значок рисуется на голове змейки. Рекорд ведётся отдельно для каждого режима.

Ускорение ×2 и возврат к обычной скорости работают во всех режимах так же: нажать в сторону движения включает ускорение, а в противоположную сторону выключает его. Режим можно выбрать и клавишами 1, 2, 3. На телефоне диагональные свайпы работают в режимах слона и ферзя.
